### 1. URL Launcher on Result Clicks (CRITICAL)
**Problem**: `ResultCard` has `on_open` callback but nothing calls `ft.UrlLauncher().launch_url()` when a result is tapped. Users can't open profile URLs in browser.

**Fix**: Wire the `on_open` callback in `results_screen.py` to call `UrlLauncher`:
```python
# In ResultsScreen, when building ResultCard:
def _open_url(url):
    async def _launch():
        await ft.UrlLauncher().launch_url(url)
    asyncio.create_task(_launch())
```

### 2. Theme Persistence (CRITICAL)
**Problem**: Home screen toggle changes `page.theme_mode` but doesn't save to `STORAGE_THEME`. Theme preference is lost on restart.

**Fix**: Add storage persistence in `_toggle_theme`:
```python
from services.storage_service import StorageService
storage = StorageService(page)
await storage.set(STORAGE_THEME, "dark"/"light"/"system")
```

**Fix**: Low priority — the storage service is lightweight and stateless (reads from file). The multiple instantiations are harmless but wasteful. Can be addressed later if needed.
